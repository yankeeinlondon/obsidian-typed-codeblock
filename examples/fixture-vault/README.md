# Fixture vault

Notes used by spike S2 (`docs/spikes/S2.md`), the scanner fixture suite (Phase 2) and manual
acceptance (Phase 8). Fences named `km-ts` / `km-js` are the "owned" fences of the example
consumer; `ts` blocks are the standard-language reference for highlighting parity.

Each note isolates one structural concern so a probe can compare Obsidian's view of the note
with the scanner's extraction.
