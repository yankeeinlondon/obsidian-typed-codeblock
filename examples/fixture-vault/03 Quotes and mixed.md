# Quotes and mixed containers

> Plain quote
> ```km-ts
> const inQuote = 1;
> ```

> > Nested quote
> > ```km-ts
> > const nestedQuote = 2;
> > ```

- List item
  > Quote inside list
  > ```km-ts
  > const listQuote = 3;
  > ```

> - List inside quote
>   ```km-ts
>   const quoteList = 4;
>   ```

> Lazy continuation must end the block
> ```km-ts
> const beforeLazy = 5;
const lazyLine = 6;
> ```
