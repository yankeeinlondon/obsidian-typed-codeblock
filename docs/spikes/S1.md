# Spike S1: Blob worker with TypeScript 6.x in Obsidian desktop

- **Date:** 2026-11-13
- **Host:** macOS (Darwin 27.2.0), Obsidian desktop **1.15.1** (installer 1.13.7), Electron 43.3.0, Chrome 150.0.7871.212
- **Build under test:** the real production artefact `dist/index.cjs` from `pnpm build` (two-stage build, see ruling 1). Its inlined worker string contains `typescript@6.0.3`, `@typescript/vfs@1.6.6` and the `/// <reference lib>` closure of `es2022`, `es2023`, `es2024`, `dom`, `dom.iterable` and `dom.asynciterable` (72 lib files).
- **Runs:** one, as planned. Mobile was not spiked. Mobile worker verification happens once, during Phase 8 acceptance.

## Method

This spike skips a separate throwaway plugin. The probe (below) ran in Obsidian's renderer through the official CLI (`obsidian-cli eval`). The renderer is the same process, with the same CSP and the same `Worker`/`Blob` implementation, that loads community plugins. The probe:

1. `require`s the built `dist/index.cjs`, which is the module a consumer plugin bundles;
2. calls `createBlobWorker()`, which creates a Blob URL from the inlined source and starts `new Worker(blobUrl)`;
3. waits for the worker's `ready` message, revokes the Blob URL, then sends one quick-info query for `const names = [{ name: 'a' }].map((p) => p.name);` at `names`.

The probe script is reproduced at the end of this file.

## Raw findings

### First run (original build): worker started, then crashed

```json
{"status":"worker-error","blobUrl":"blob:app://obsidian.md/bfc67c28-…","error":"Uncaught TypeError: l.platform is not a function"}
```

- The Blob URL worker **was created**. There was no CSP or Blob error. The page CSP is only `style-src 'unsafe-inline' 'self' https://fonts.googleapis.com`, and it has no `worker-src`/`script-src` restriction.
- **Root cause:** Obsidian desktop workers have **Node integration**. A probe worker reported `typeof process === "object"`, `typeof require === "function"`, `typeof module === "object"` and `typeof process.nextTick === "function"`. TypeScript's `isNodeLikeSystem()` (`process && process.nextTick && !process.browser && require`) is therefore `true`. TypeScript builds its Node `sys` and calls `require("os").platform()`, which hits the empty Node built-in shim in our worker bundle.
- **Fix (in `scripts/build.ts`):** stage 1 compiles every `process` reference to `undefined` (`define: { process: "undefined" }`). TypeScript and `debug` then take the same browser code path on desktop, mobile and plain browsers. Regression test: `tests/unit/build-output.test.ts` › "stays on the browser code path inside an Obsidian desktop worker that exposes Node globals". It reproduced the exact `l.platform is not a function` error before the fix.

## Decision impact

- **Phase 4 / FR-23:** the Blob-URL worker deployment contract works on Obsidian desktop as specified. Keep `define: { process: "undefined" }` in the worker build, together with the "Obsidian-like globals" regression test. Worker code must never rely on `process`/`require` being absent: on desktop they exist, but they must not be used (§7.4).
- **Phase 4 (timeout):** a cold start of ~1.3 s is well within the fixed 30 s timeout (ruling 12).
- **§9 cold-start target (< 1.5 s, first block → first completion):** about 1.32 s + 90 ms ≈ 1.41 s in this one sample. That is close to the budget. Phase 8's measurement should compare against this number. Shipping the libs closure with only the libs a consumer selects is not possible, because the string is built once. Shrinking lib text (stripping comments) is a candidate optimisation if Phase 8 finds a problem.
- **Ruling 10 (minimum Obsidian version):** evidence so far is Obsidian 1.15.1 / Electron 43. Phase 8 sets the minimum.

## Probe script

```js
(() => {
  const started = performance.now();
  const out = (window.__tcbS1 = { status: "starting" });
  const mod = require("/Volumes/coding/personal/typed-code-block/dist/index.cjs");
  let blobUrlSeen;
  const env = {
    createObjectURL: (b) => (blobUrlSeen = URL.createObjectURL(b)),
    revokeObjectURL: (u) => { URL.revokeObjectURL(u); out.revoked = u === blobUrlSeen; },
    createWorker: (u) => new Worker(u, { name: "obsidian-typed-codeblocks" }),
  };
  const handle = mod.createBlobWorker(undefined, env);
  handle.worker.onerror = (e) => { out.status = "worker-error"; out.error = String(e.message || e); };
  handle.worker.onmessage = (e) => {
    const m = e.data;
    if (m.op === "ready") {
      handle.revokeUrl();
      out.ready = m; out.coldStartMs = performance.now() - started;
      const code = "const names = [{ name: 'a' }].map((p) => p.name);";
      out.queryAt = performance.now();
      handle.worker.postMessage({ id: 1, op: "quickInfo", code, position: code.indexOf("names") });
    } else {
      out.reply = m; out.roundTripMs = performance.now() - out.queryAt; out.status = "done";
      handle.worker.terminate();
    }
  };
  return "launched";
})()
```
